⚙ 設定（GitHubトークン）

トークンを登録すると、OK/ポスト削除を押すだけでGitHubの画面を開かずに送信できます。トークンはこのブラウザの中（localStorage）だけに保存され、api.github.com 以外には送られません。

  1. トークン作成ページを開く（yui0811でログイン）
  2. Token name：好きな名前（例: picker）、Expiration：お好みで
  3. Repository access：Only select repositories → yui-post-picker を選ぶ
  4. Permissions → Repository permissions → Issues：Read and write
  5. 「Generate token」を押して、表示された github_pat_… をコピーして下に貼り付け
